The Last Ensembl Plants Site

Gramene 70 was synchronized with the last release of Ensembl Plants as a separate division from Ensembl. Since then, it has been unified into a single Ensembl site, which providing access to genomes from projects such as Darwin Tree of Life, the Human Pangenome Reference Consortium, the Vertebrate Genomes Project, and the European Reference Genome Atlas

From more information on the new Ensembl, go to 'About the ENSEMBL project'.
